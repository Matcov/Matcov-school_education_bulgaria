# Результаты школьных экзаменов в Болгарии: обзор проекта

Этот документ описывает архитектуру, данные и функциональность проекта, реализованного в [alex_school_results.py](../alex_school_results.py), с локальной базой данных [school_results.db](../school_results.db) и архивом по школам в папке [schools/](../schools/).

---

## 1. Краткое резюме

* **Официальный источник данных:** Результаты по отдельным школам публикуются не в виде таблиц на веб-страницах Министерства образования и науки (`mon.bg`), а как наборы открытых данных на **Портале открытых данных Республики Болгария** ([data.egov.bg](https://data.egov.bg)).
* **Охват:** Проект охватывает **4 основных набора данных** (НВО в 4, 7 и 10 классе, а также ДЗИ в 12 классе) с **25 годовыми файлами**, содержащими данные о **2 379 школах** за период с 2018/2019 по 2025/2026 учебный год.
* **Приложение:** [alex_school_results.py](../alex_school_results.py) предоставляет интерактивную веб-панель (на Gradio), которая позволяет фильтровать, сравнивать, составлять рейтинги, смотреть карту неравенства между областями и его изменение по годам, а также получать анализ результатов с помощью ИИ.
* **Локальная база данных:** Результаты хранятся в базе SQLite [school_results.db](../school_results.db) (8,1 МБ). Приложение запускается за секунды, работает без интернета и обращается к государственным сайтам только при нажатии зелёной кнопки **«Проверить новые результаты»**.
* **Архив школ:** Папка [schools/](../schools/) содержит отдельный CSV-файл для каждой школы с историей всех её результатов (снимок на 17 ноября 2026 г.).

---

## 2. Источники данных и интеграция с API

> Государственные сайты используются только для заполнения и обновления локальной базы данных: при первом запуске (если база пуста) и при нажатии зелёной кнопки **«Проверить новые результаты»**.

### Министерство образования и науки (МОН)
1. Скрипт читает официальную страницу [mon.bg → Отворени данни](https://www.mon.bg/mon/dostap-do-informatsiya/otvoreni-danni/) (Открытые данные) с помощью `BeautifulSoup`.
2. Извлекает ссылку на профиль министерства на национальном портале открытых данных (`organisation id 117`).
3. Публичные страницы МОН содержат примерные варианты экзаменов и шкалы оценивания, а индивидуальные результаты учеников находятся на `infopriem.mon.bg` (для доступа нужны входящий номер и код, поэтому они не публичны и не обрабатываются).

### Портал открытых данных (data.egov.bg)
Все запросы выполняются через HTTP `POST` к адресу API `https://data.egov.bg/api/<method>` с телом в формате JSON:
* `getOrganisationDetails`: получает внутренний числовой идентификатор МОН.
* `listDatasets`: перечисляет наборы данных министерства (100 записей на страницу).
* `listResources`: возвращает список файлов (ресурсов) конкретного набора данных.
* `getResourceData`: загружает содержимое выбранного файла в виде строк таблицы.

#### Основные наборы данных:
| Экзамен | Название набора на портале | Охваченные годы | Шкала оценивания |
|---|---|---|---|
| **НВО, 4 класс** | Резултати по училища от националното външно оценяване за IV клас | 2020/21 – 2025/26 | Баллы (макс. 100) |
| **НВО, 7 класс** | Резултати по училища от националното външно оценяване за VII клас | 2018/19 – 2025/26 | Баллы (макс. 100) |
| **НВО, 10 класс** | Резултати по училища от националното външно оценяване за X клас | 2020/21 – 2025/26 | Баллы (макс. 100) |
| **ДЗИ (матура)** | Резултати от държавните зрелостни изпити по училища и по предмети | 2021/22 – 2025/26 | Оценка (от 2,00 до 6,00) |

> **Примечание о ДЗИ:** Для каждого года выбирается только основная сессия (май–июнь) с обязательными экзаменами (БЕЛ и второй обязательный ДЗИ / ДИППК).

## 3. Обработка и нормализация данных

Входящие файлы с государственного портала содержат ряд различий в форматировании, которые скрипт нормализует автоматически:
* **Уникальный ключ школы:** Названия школ меняются и сокращаются с годами. Проект использует **код по НЕИСПУО (админ-код)** как единственный надёжный уникальный идентификатор.
* **Форматирование кодов:** Удаляются пробелы (например, `2 216 001` становится `2216001`), чтобы избежать искусственного дублирования школ.
* **Нормализация населённых пунктов:** Унифицируются написания вроде `ГР. СОФИЯ` и `ГР.СОФИЯ`, районы Софии сводятся к `ГР.СОФИЯ`, а школы за рубежом обозначаются единообразно.
* **Оценки и числа:** Обрабатываются десятичные запятые (`3,09` → `3.09`), пустые ячейки и нули при отсутствии явившихся учеников.
* **Второй обязательный экзамен ДЗИ:** Поскольку выпускники сдают разные предметы в качестве второго экзамена, скрипт вычисляет единую среднюю оценку за второй ДЗИ, взвешенную по числу явившихся учеников по каждому предмету.
* **Взвешенные средние значения:** Общие средние оценки для городов, областей и всей страны всегда вычисляются как средние, взвешенные по числу учеников, а не как среднее арифметическое средних по школам.

## 4. Локальная база данных (`school_results.db`)

* **Формат:** SQLite — встроена в Python (без дополнительных установок). Вся база — это один файл, по которому можно искать с помощью SQL.
* **Таблицы:**
  * `files` — по одной строке на каждый файл с результатами, т. е. один экзамен в одном учебном году (25 строк): экзамен, учебный год, вид (`nvo` или `dzi`), идентификатор файла на data.egov.bg и дата загрузки.
  * `results` — по одной строке на каждую школу в каждом файле (35 292 строки), уже очищенные и нормализованные.
  * `checks` — по одной строке на каждую проверку новых результатов.
* **Скорость:** Запуск занимает около 1 секунды вместо примерно 15, а загрузка одного экзамена за один год — около 20 миллисекунд вместо примерно 1 секунды.
* **Обновление:** Зелёная кнопка **«Проверить новые результаты»** проверяет портал (около 20 секунд) и загружает только те файлы, которых нет в базе или которые министерство заменило исправленной версией. Каждый файл записывается в одной транзакции, поэтому прерванное обновление не оставляет половину файла.
* **Первый запуск:** Если база отсутствует или пуста, приложение заполняет её автоматически (около минуты).
* **Проверка:** База, построенная из всех 25 файлов, идентична свежей загрузке каждого файла — каждая школа, каждое число, каждая пустая ячейка и тип каждого столбца.

## 5. Возможности веб-приложения (alex_school_results.py)

Пользовательский интерфейс построен на **Gradio** (`gr.Blocks`) и содержит три вкладки. Над ними находится строка с состоянием базы данных (число файлов и дата последней проверки) и зелёная кнопка **«Проверить новые результаты»**. Все остальные кнопки светло-серые, поэтому зелёная кнопка выделяется. Три вкладки — зелёные кнопки посередине страницы; открытая темнее и подчёркнута.

### Вкладка «Школы»
* **Фильтрация:** Выбор экзамена и учебного года, области и населённого пункта (список городов и сёл динамически фильтруется по выбранной области).
* **Поиск:** Поиск по свободному тексту по школе, городу или общине (на кириллице).
* **Сортировка:** Рейтинг по БЕЛ или по математике / второму экзамену.
* **Сводная статистика:**
  * Средний результат и число явившихся учеников для выбранного фильтра.
  * Прямое сравнение среднего результата со средним по соответствующей области и по стране.
  * Место выбранного города среди всех населённых пунктов Болгарии и внутри области (применён порог минимального числа учеников: не менее 100 учеников на национальном уровне и не менее 30 учеников внутри области).

### Вкладка «Топ-5 пунктов и школ + обзор ИИ»
* **Рейтинг первых 5 населённых пунктов и школ:** Рассчитан по общему среднему результату по двум предметам.
* **Создание структурированного текстового анализа:** С помощью локальной языковой модели в **Ollama** (`gemma4`).
* **Архитектурный принцип:** *Все вычисления выполняет программный код, а не языковая модель.* Код вычисляет отклонения от среднего значения («К среднему» — по сравнению со средним по области) и передаёт модели готовые числа, чтобы предотвратить математические ошибки и галлюцинации.
* **Запасной вариант без ИИ:** Если Ollama не работает, модель не загружена или во время написания возникает ошибка, программа сама пишет обзор по тем же числам — мгновенно, с пометкой о причине.

### Вкладка «Карта и тренды областей»
* **Сравнение всегда со средним результатом по стране:** Так нейтрализуется разница в сложности тестов от года к году, и годы можно честно сравнивать.
* **Три представления, переключаемые тремя светло-серыми кнопками:**
  * **«Отличие от Болгарии»:** Карта 28 областей, окрашенных по отклонению от среднего результата по стране: от тёмно-красного (намного ниже среднего), через жёлтый (около среднего), до светло-зелёного (намного выше среднего). Рядом — столбчатая диаграмма с точным отклонением каждой области и сводка разрывов: лучшая область против худшей, города против сёл.
  * **«Изменение за год»:** Та же карта и диаграмма, окрашенные по тому, насколько изменилось отклонение каждой области от среднего по стране по сравнению с предыдущим годом. Сводка называет области с наибольшим улучшением и с наибольшим отставанием, а также типичное изменение (медиану), потому что небольшие изменения часто бывают случайными колебаниями.
  * **«Тренды по годам»:** Таблица с цветными ячейками (по одной строке на каждую область и по одному столбцу на каждый год) с отклонением области от среднего по стране, и линейная диаграмма разрыва между лучшей и худшей областью. Например, для 7 класса этот разрыв растёт с 20,58 балла (2018/19) до 26,79 балла (2025/26).
    * В некоторые годы тест сильнее разбрасывает учеников, и это само по себе увеличивает разрыв. Поэтому сводка сравнивает разрыв ещё и с разбросом результатов школ в том же году (стандартным отклонением). По этой мере разрыв в 7 классе растёт на 12%, а не на 30%, и только до 2021/22. В 10 классе области даже немного сближаются.
* **Цвета становятся всё светлее** по мере улучшения результатов, поэтому все три представления читаются и людьми с дальтонизмом, и в чёрно-белом виде.
* **Примечание под картой:** цвета показывают различия в результатах, а не качество школ.
* **Границы областей:** Natural Earth (общественное достояние), в файле [bulgaria_regions.geojson](../bulgaria_regions.geojson).

### Четыре языка
* **Синие кнопки EN BG RU RO** рядом с заголовком переключают всю страницу: подписи, сводки, диаграммы и обзор ИИ. Болгарская версия открывается по основному адресу (`http://127.0.0.1:7860`), английская, русская и румынская — по адресам `/en`, `/ru` и `/ro`.
* **Все тексты в одном файле,** [translations.py](../translations.py): 137 текстов, каждый на 4 языках. При запуске приложение проверяет, что ни один перевод не пропущен.
* **Вычисления одинаковы на всех языках:** списки показывают переведённые подписи, но передают коду одни и те же английские значения.
* **Без изменений остаются:** названия школ, населённых пунктов и областей (как их пишет министерство) и десятичная точка (55.28). Целые числа вне английской версии пишутся с пробелом между тысячами (53 739).

## 6. Структура папки `schools/`

* **2 379 отдельных CSV-файлов:** Формат имён — `<име на училище> - <град> (<код>).csv` (название школы, город, код).
* **Файл-индекс:** `_all_schools.csv` содержит список всех школ с их кодами, областями, городами и числом доступных результатов по годам.
* **Кодировка:** Файлы сохранены в `UTF-8 with BOM`, что обеспечивает беспроблемное открытие кириллицы в Microsoft Excel.
* **Снимок:** Файлы отражают данные на 17 ноября 2026 г. Актуальная, обновляемая копия — это база данных `school_results.db`.

## 7. Запуск проекта

### Требования:
1. Установленный менеджер пакетов Python `uv` (или библиотеки из [requirements.txt](../requirements.txt): `gradio`, `pandas`, `plotly`, `requests`, `beautifulsoup4`, `ollama`).
2. (По желанию, для анализа ИИ) Запущенный **Ollama** с загруженной моделью. Без него программа сама пишет более простой обзор.
   ```bash
   ollama pull gemma4
   ```

### Команда для запуска:
Из корневой папки проекта:
```bash
uv run education_bulgaria/alex_school_results.py
```
Из загруженной копии репозитория GitHub:
```bash
python alex_school_results.py
```
Приложение запускается за несколько секунд из базы данных и автоматически открывается в браузере (обычно по адресу `http://127.0.0.1:7860`). Для работы с ним интернет не нужен — он требуется только для кнопки **«Проверить новые результаты»**.
